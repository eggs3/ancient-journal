The Locked Drawer

Your journal's pages are kept safe in a strongbox on GitHub, not in this browser alone. Furnish the following particulars once, and it shall remember them here henceforth.

How do I get a token? (once-only ritual)
  1. Create a new GitHub repository (public or private, either works) — this is where your entries will live, and where this site will be hosted.
  2. Upload these journal files to it, then in the repo's Settings → Pages, set the source to your main branch so the journal is reachable by web address.
  3. Go to GitHub → your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  4. Give it a name, set Repository access to "Only select repositories" and choose this repo.
  5. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else as-is.
  6. Generate it, copy the token, and paste it above. It is stored only in this browser's local storage — never committed anywhere.
